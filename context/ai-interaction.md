# AI Interaction Guidelines

## Communication

- Be concise and direct

## Workflow

This is the common workflow that we will use for every single feature:

1. **Document** - Document the feature in @context/current-feature.md
2. **Branch** - Create a new branch for feature
3. **Implement** - Implement the feature from #context/current-feature.md
4. **Commit** - Only after build passes and everything works
5. **Merge** - Merge to main
6. **Delete Branch** - Delete branch after merge
7. **Log** - Add history in @context/current-feature.md

## Commits

- Never put "Generated With Claude" in the commit message
